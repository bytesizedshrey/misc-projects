
# Sound Files Needed

This directory should contain the following sound files:
- `cyberpunk-beat.mp3` - A background cyberpunk/synthwave beat for the main audio
- `power-up.mp3` - Sound effect for enabling ROBO MODE
- `power-down.mp3` - Sound effect for disabling ROBO MODE
- `glitch.mp3` - Glitch sound effect for robot interactions
- `beat-drop.mp3` - Beat drop sound effect for robot interactions
- `scratch.mp3` - DJ scratch sound effect for robot interactions

You can find royalty-free sound effects on websites like:
- https://freesound.org/
- https://pixabay.com/sound-effects/
- https://elements.envato.com/sound-effects (paid)
